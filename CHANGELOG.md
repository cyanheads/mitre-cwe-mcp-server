# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-30

Load CWE 5.0 catalogs and publish a CWE/CAPEC guide over MCP, with mcp-ts-core 0.13.18 and updated artifact delivery.

CWE and CAPEC retrieval preserves prose structure and provides complete follow-up calls.

A last-known-good catalog cache lets the server start while MITRE is unreachable; search matches tokens at word starts and gains taxonomy-mapping and observed-example CVE filters; example code, emphasis, and link text normalize faithfully.

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-21

Catalog prose keeps its source text, filter-defined views and CAPEC categories and views resolve, hierarchy edges and previews are corrected, and alternate terms, notes, and mapping usage are returned, with alternate terms searchable.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-20

Search CWE weaknesses and CAPEC attack patterns, retrieve selected details, and navigate live CWE hierarchies.
