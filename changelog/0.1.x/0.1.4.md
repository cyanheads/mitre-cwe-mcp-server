# 0.1.4 — 2026-10-24

## Changed

- **Text filters** match tokens of at least four Unicode letters after exactly one `un` or `mis` prefix at a word start across both searches and reference labels; spelling coincidences remain possible. ([#32](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/32))

## Fixed

- **Prose indentation** renders `margin-left` divs as nested CommonMark blockquotes while preserving source text and inline structure. ([#28](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/28))
- **Nested empty lists** retain their items and nesting without becoming thematic breaks or code blocks. ([#31](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/31))
- **Detail re-calls** group omitted sections by complete response size and keep example filters and paging only on the examples group; an oversized single section remains intact with disclosure. ([#29](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/29))
- **Hierarchy deadlines** return retryable `hierarchy_timeout` for active and queued expiry, with recovery distinguishing recorded relations from live traversal; caller cancellation remains nonretryable. ([#33](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/33))
