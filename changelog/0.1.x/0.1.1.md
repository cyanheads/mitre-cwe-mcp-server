# 0.1.1 — 2026-10-20

## Added

- **Seven read-only tools** cover CWE and CAPEC search, selected detail sections, complete code examples, curated views, live hierarchy traversal, and reference vocabulary.
- **In-memory catalogs** load before serving, refresh CWE daily and CAPEC weekly, and disclose provenance and failed refreshes while retaining the last good snapshot.
- **MITRE attribution** and data-license notices accompany npm, Docker, and desktop bundle artifacts.

## Fixed

- **Response budgets** defer whole IDs, items, or hierarchy edges with continuation; explicit detail selections remain complete with oversized-result disclosure ([#1](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/1)).
- **Hierarchy recovery** preserves queue-capacity guidance ([#2](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/2)).
- **Catalog links** preserve safe destinations and render unsafe destinations as inert text ([#3](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/3)).

## Dependencies

- Added `fast-xml-parser ^5.11.2`, `fast-xml-validator ^1.4.2`, and `fflate ^0.8.3` for ordered XML parsing, validation, and bounded ZIP decompression.
