# 0.1.3 — 2026-10-23

## Added

- **`CWE_CACHE_DIR`** holds each successful MITRE download; a later start loads the saved copy without a request and checks MITRE right after, retrying a failed check after 5, 10, 20, 40, then every 60 minutes. Defaults to a per-user cache directory, and the Docker image mounts `/usr/src/app/.cache` as a volume ([#23](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/23)).
- **`source` (`cache` | `upstream`) and `fetchedAt`** on `cwe_list_reference` topic `versions` `catalogs[]` ([#23](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/23)).
- **`taxonomyName`, `taxonomyEntryId`, and `observedCveId`** filters on `cwe_search_weaknesses` return `matchedTaxonomyMappings` and `matchedObservedExamples`; `cwe_list_reference` `filter_values` lists `cweTaxonomyNames` ([#27](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/27)).
- **`references`** on each CWE demonstrative example, beside its `blocks` ([#24](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/24)).
- **Public hosted endpoint** `https://mitre-cwe.caseyjhand.com/mcp` in the README and `server.json` `remotes`.

## Changed

- **Text `filter` tokens** on both search tools and `cwe_list_reference` match at a word start or camelCase hump, never inside a word: `rce` no longer matches `resource`, and `serialization` no longer finds CWE-502 (search `deserialization`) ([#25](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/25)).

## Fixed

- **`cwe_get_weakness`** applies `exampleLanguage`, `exampleOffset`, and `exampleLimit` when `sections` is omitted by adding `examples` to the defaults; an explicit `sections` without `examples` gets guidance naming the re-call ([#26](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/26)).
- **`filter_values` `cweStatuses`** lists only statuses weaknesses carry; `status` `Obsolete` answers zero rows with a notice that it occurs only on categories ([#20](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/20)).
- **Example code** keeps its indentation (4 spaces per `margin-left` level), drops the XML file's whitespace, and breaks lines at block elements; an example's References are no longer empty prose blocks ([#24](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/24)).
- **Bold and italic** beside generated syntax or another span drop delimiters that cannot flank instead of rendering literal asterisks ([#21](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/21)).
- **Generated links and code spans** keep a preceding `!` as text, keep adjacent code spans separate, and keep the text of a link that crosses a block boundary ([#30](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/30)).

## Dependencies

- `ignore ^7.0.12 → ^7.0.13` (dev); Bun `1.4.3 → 1.4.4` (`packageManager`, Dockerfile base image).
