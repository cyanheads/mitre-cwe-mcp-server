# 0.1.2 — 2026-10-21

## Added

- **`alternateTerms`** in the `summary` section of `cwe_get_weakness` and `cwe_get_attack_pattern`; both search tools match a term as part of the record name, so `XSS`, `ReDoS`, and `MITM` find their entries ([#11](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/11)).
- **`cwe_get_attack_pattern`** returns CAPEC categories and views (`entries[].type`; `abstraction` only on patterns) with `members`, mappings, and notes ([#9](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/9)).
- **`ordinalities`, `backgroundDetails`, `functionalAreas`, `affectedResources`**, resolved `relatedWeaknesses[].name`, and a `notes` section on weaknesses, categories, CAPEC records, and `cwe_get_view` ([#12](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/12)).
- **`mappingUsage`** result field and filter on `cwe_search_weaknesses`, listed under `cwe_list_reference` topic `filter_values` ([#15](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/15)).
- **`kind: "partial"`** detail entries keep the default sections that fit the response budget and list the rest in `outline` ([#13](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/13)).
- **`invalid_id`** per-item miss reason, and ID forms such as `CWE79`, `cwe 079`, `CWE_79`, and `capec_066` ([#14](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/14)).

## Changed

- **Malformed single IDs** return `-32602 invalid_arguments` naming the accepted forms (previously `-32007`); `unknown_filter` errors carry `field`, `value`, and `supported` in `error.data` ([#14](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/14)).
- **Page fitting** binary-searches the item count instead of re-rendering every count from the limit; pages are unchanged ([#19](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/19)).
- **Keywords** on `package.json` and both plugin manifests add `cybersecurity`, `vulnerability`, `secure-coding`, and `threat-modeling`.

## Fixed

- **Hierarchy** direct `children` and `parents` match the same-view tree, including category and view parents, instead of failing without `ViewID` or returning no edges ([#5](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/5)).
- **`cwe_get_hierarchy` pages** carry only the nodes of their own edges, so `viewId: "all"` no longer repeats the root per view ([#6](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/6)).
- **Filter-defined (Implicit) views** keep their XPath `filterDefinition` and `cwe_search_weaknesses` with their `viewId` returns the matching weaknesses ([#7](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/7)).
- **Catalog prose** stores source text without backslash escapes and `&amp;`, so `varname_size` and `<script>` are searchable ([#8](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/8)).
- **`content[]` cursors, IDs, and filter values** render without backslash escapes and can be passed back as input ([#16](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/16)).
- **`descriptionPreview`** ends at the first complete sentence instead of at `.NET`, `(e.g.`, or an open bracket ([#10](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/10)).
- **Prose tables, images, and superscripts** convert to pipe tables, `![alt](url)`, and `^text` instead of losing content ([#18](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/18)).
- **An HTTP 403 from MITRE** returns a retryable `ServiceUnavailable` that says to wait before repeating the call, instead of a permanent `Forbidden` ([#17](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/17)).
- **A text `filter` holding a control character U+0000–U+0008 or U+000E–U+001F** is rejected as `invalid_arguments` on `cwe_search_weaknesses`, `cwe_search_attack_patterns`, and `cwe_list_reference`; catalog text cannot contain those characters, so such a filter never matched.

## Dependencies

- Added dev dependencies `commonmark 0.31.2` and `@types/commonmark 0.27.10` for Markdown round-trip tests.
