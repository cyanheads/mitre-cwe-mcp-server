# 0.2.0 — 2026-10-30

## Added

- Serve the mitre-cwe-guide skill as the MCP resource `skill://mitre-cwe-guide/SKILL.md`.
- **Agent Plugins** — add the root `plugin.json` and `mcp.json` pair; ship the guide in npm, Docker, and MCPB artifacts.

## Changed

- **MCPB delivery** — prune dependency agent docs, build-only files, and node-gyp intermediates while retaining SDK runtime skill modules and the published guide.
- **Getting started** — show hosted and local Claude Code commands, a shared client config, and Docker instructions under Running the server.
- **Framework tooling** — synchronize development skills, packaging checks, audit classification, and the bug-report Environment table; set the dependency minimum release age to one day.

## Fixed

- **CWE 5.0 ingestion** — accept schema 8 alongside schema 7, retain grouping identity in details and live hierarchy, and expose separate grouping counts ([#36](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/36)).
- **Schema-8 evidence** — preserve ordered standard/custom phases and domains, technical nuance, dimensions, alternate-term roles, and sparse platform, note, observed-example, and reference metadata in existing sections; standard-phase view filters exclude custom phases.
- **Error text** — pass raw vocabulary values to the framework error renderer so Markdown escaping is applied once.
