# 0.3.0 — 2026-11-11

## Added

- **CWE mapping notes** retain MITRE's suggested remap IDs, source comments, and resolved names. ([#38](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/38))
- **CAPEC relations** include direct child patterns in numeric ID order, with names, abstraction, and recorded statuses. ([#39](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/39))
- **Platform filters** report how many matching platform-independent weaknesses the language or technology filter excluded. ([#42](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/42))

## Changed

- **Detail `entries[].kind`** is now `full` or `outline`. Update consumers to drop the `partial` branch and request `sections: []` for outlines. ([#41](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/41))
- **Response sizes** follow item counts. Lists honor the requested page size up to each tool's cap, and detail calls return complete default or selected sections for up to 20 distinct IDs. Follow `nextCursor` or `deferredIds` for additional records.
- **Text filters** match closed spellings of hyphenated compounds, such as `hardcoded` for `hard-coded`. ([#43](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/43))
- **Guide and tooling** reflect the new detail and search behavior and sync framework tooling and configuration guidance.

## Fixed

- **CWE ZIP refresh** uses ETag or Last-Modified even when the REST version stays the same. HTTP 304 preserves catalog origin and download time. ([#40](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/40))
- **CAPEC zero-hit guidance** suggests `includeInactive` only when inactive patterns match the other filters. ([#44](https://github.com/cyanheads/mitre-cwe-mcp-server/issues/44))
